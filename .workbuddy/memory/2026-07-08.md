### 构建反散户情绪择时指标工具 (anti-retail-sentiment.html)

基于行为金融学"过度反应理论"，开发了一个根据市场恐慌程度给出买入建议的股票推荐工具。

**核心算法 — 反散户恐慌指数 (0-100)：**
- 成交量萎缩度（18/25分）：日均成交从3.55万亿峰值萎缩至2.6-2.8万亿
- 融资余额变化（14/20分）：从3万亿回落，近两周净流出约420亿
- 市场宽度（16/20分）：涨跌比持续偏弱
- 指数回撤（8/15分）：上证从4,175回撤至4,011
- 媒体情绪（8/10分）：恐慌关键词频繁出现
- 新增开户动能（3/10分）：唯一偏乐观因子

**当前恐慌指数 = 67/100 → 中度恐慌 → ★★★★ 建议分批买入**

**数据来源：** Wind、中证数据、腾讯自选股（通过 neodata + westock-data 获取）

**技术实现：** 纯前端 HTML + ECharts，含仪表盘、趋势图、股票推荐池。JS语法已校验通过。

### v2.1 修复：搜索功能重构

问题根因：
1. `document.addEventListener('click')` 与下拉菜单项 `onclick` 冲突 → 改为 `mousedown` + `contains` 判断
2. 匹配逻辑过严（只匹配代码/全名） → 增加模糊别名索引，支持简称、拼音、部分代码匹配
3. 5日/10日数据缺失导致表格列错位 → 精简为今日/20日/60日/年初至今/52周高

改进：
- 搜索逻辑包裹在 IIFE 中，增加 try-catch 容错
- 下拉菜单使用 `mousedown` + `data-code` 属性绑定，避免 inline onclick 编码问题
- Enter 键自动选中第一个匹配结果
- Escape 键关闭下拉
- 全局暴露 `window.analyzeStock` / `window.selectStock` 保持兼容

### v3 升级：全市场股票覆盖（A股+港股+美股）

架构：离线股票数据库（stocks_db.json）+ 本地搜索，无需后端服务。

数据规模：155只核心股票
- A股 91只：沪深300 + 中证500 核心成分股（含实时行情）
- 港股 30只：恒指成分股 + 科技龙头
- 美股 34只：纳指100科技龙头 + 中概股

数据生成流程：
1. 手写核心股票列表
2. 通过 westock-data 批量拉取 A 股实时行情（91只，分6批，~12秒）
3. 输出 stocks_db.json，前端启动时异步加载合并

技术细节：
- westock-data 行情字段索引：20=PE, 23=PB, 29=52周高, 33=20日, 34=60日, 35=年初至今
- 港股/美股暂缺实时行情，搜索可见但分析提示"暂无数据"
